# Meeting Attendant Agent Skill

**Skill Name**: meeting-attendant
**Tier**: Gold Tier - US6
**Description**: Automated meeting attendance, transcription, and note generation

## Purpose

The Meeting Attendant agent skill enables the AI Employee to attend video meetings (Zoom/Meet/Teams), record audio, transcribe conversations, extract action items, and generate structured meeting notes automatically.

## Capabilities

1. **Meeting Attendance** (Future: requires Zoom SDK)
   - Join scheduled meetings from calendar
   - Announce presence and request recording consent
   - Record meeting audio

2. **Audio Transcription**
   - Transcribe using OpenAI Whisper API
   - Fallback to local Whisper model if API unavailable
   - Generate timestamped transcripts
   - Confidence scoring (0.0-1.0)

3. **Note Generation**
   - AI-generated summary
   - Key discussion points extraction
   - Decisions made identification
   - Action item extraction with assignees and deadlines
   - Important moment highlights with timestamps

4. **Task Creation**
   - Automatic task file creation in /Needs_Action/
   - Link tasks to meeting notes
   - Include context and assignee information

5. **Encryption Support**
   - Encrypt sensitive transcripts
   - Encrypt recording links
   - Secure storage in vault

## Usage

### Generate Notes from Recording

```bash
# Using meeting service directly
python src/services/meeting_service.py /path/to/vault /path/to/recording.m4a
```

### From Python

```python
from src.services.meeting_service import MeetingService
from datetime import datetime

service = MeetingService(vault_path="/path/to/vault")

# Generate notes from existing recording
meeting_metadata = {
    "title": "Q2 Planning Meeting",
    "meeting_id": "CAL_abc123",
    "meeting_date": datetime.now(),
    "attendees": [
        {"name": "John Smith", "email": "john@example.com", "role": "PM"},
        {"name": "Jane Doe", "email": "jane@example.com", "role": "Engineer"}
    ],
    "duration_minutes": 60,
    "recording_consent": True
}

notes = service.generate_notes_from_recording(
    recording_path="/path/to/recording.m4a",
    meeting_metadata=meeting_metadata,
    encrypt_sensitive=False
)

print(f"Notes created: {notes.note_id}")
print(f"Action items: {notes.get_action_item_count()}")
```

## Troubleshooting

### Transcription Fails

**Problem**: Whisper API returns error

**Solution**:
- Check OPENAI_API_KEY is set correctly
- Verify audio file format (supported: mp3, m4a, wav, webm)
- Enable local Whisper fallback: `pip install openai-whisper`

### Low Confidence Scores

**Problem**: Transcript confidence <75%

**Causes**:
- Poor audio quality (background noise, echo)
- Multiple overlapping speakers
- Non-standard accents or technical jargon

**Solutions**:
- Use higher quality audio recording settings
- Reduce background noise in meeting environment
- Review and edit transcript manually

### Action Items Not Detected

**Problem**: Meeting had action items but none extracted

**Causes**:
- Action items not stated clearly with assignee/deadline
- Non-standard phrasing

**Solutions**:
- Use standard action item formats in meetings:
  - "[Name] will [action] by [date]"
  - "Action item for [name]: [task]"
- Manually add action items to meeting notes after generation

## Integration with Calendar

The Meeting Attendant integrates with Calendar Service (US2) to:

1. Detect upcoming meetings from calendar events
2. Automatically join meetings 1 minute after start time
3. Link meeting notes to calendar events via `meeting_id`
4. Update calendar event with notes link after generation

## Best Practices

1. **Recording Consent**: Always announce recording and obtain consent
2. **Audio Quality**: Use high-quality microphones and reduce background noise
3. **Action Item Clarity**: State action items clearly with assignee and deadline
4. **Regular Review**: Review auto-generated notes for accuracy
5. **Sensitive Meetings**: Enable encryption for confidential discussions
6. **Transcript Editing**: Edit transcripts if confidence <80%
